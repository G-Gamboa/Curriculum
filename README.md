# Portafolio Profesional — Guillermo Gamboa

CV/portafolio web personal. Diseño estático con HTML, CSS y JavaScript vanilla — sin dependencias ni frameworks.

## Vista previa

![Hero del CV](Perfil.png)

## Tecnologías

| Capa | Detalle |
|------|---------|
| Estructura | HTML5 semántico |
| Estilos | CSS3 con custom properties, Grid y Flexbox |
| Scripts | JavaScript vanilla (ES2020+) |
| Tipografía | Google Fonts — DM Serif Display + DM Sans |

## Estructura del proyecto

```
Curriculum/
├── index.html   # Página principal
├── Style.css    # Estilos (variables, layout, responsive)
├── Main.js      # WhatsApp opener + favicon dinámico
└── Perfil.png   # Foto de perfil
```

## Características

- **Diseño responsive** — se adapta a móvil (≤480 px), tablet (≤860 px) y desktop
- **Hero con foto** — imagen anclada al borde inferior del encabezado
- **Portafolio de proyectos** — cards enlazadas a repositorios de GitHub
- **Contacto directo** — chip de email y botón de WhatsApp con mensaje predefinido
- **Favicon generado por JS** — monograma SVG sin archivo externo
